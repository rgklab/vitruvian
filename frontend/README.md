# Vitruvian Frontend
This is the frontend of the Vitruvian web application based on `React` and `JavaScript`.

## Install the frontend
Install frontend dependencies:
   ```bash
   cd frontend
   npm install
   ```

## To run the frontend
```bash
cd frontend
npm run start
```

## Note on Anatomical Models
Vitruvian uses two 3D human body models. One is a simplified model created by [Meshcapade](https://meshcapade.com/). The other is a medically-accurate model created by the [NIH National Library of Medicine](https://www.nlm.nih.gov/research/visible/visible_human.html).

These two models should be downloaded and placed in the `frontend/models` directory.

Should you require assistance with obtaining these models, contact the model and/or repository owners.
